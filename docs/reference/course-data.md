> **この資料は古い。** コースの形は、ユーザー提供の `docs/reference/jra-tracks/`（形状モデル・発走地点・標高）に置き換えた。下の楕円による近似とコーナー半径の推定はもう使っていない。公式値（1周・直線・高低差）の表と出典は参考として残す。

ゲームのコースの形（`src/sim/venues.ts`）の元資料。2026-10-09 に Claude がウェブ検索で集めた。

## 確度について

- **1周距離・直線距離・高低差**：JRAのコース紹介ページの値を、検索結果の要約で確認したもの（Aコース）。この環境からは JRA のサイトを直接開けなかったので、ページ本体は見ていない。ダートの値は JRA の値を引用した解説サイト経由
- **距離ごとの内回り・外回り**：JRAのコース紹介の発走距離欄を、検索結果の要約で確認したもの。両方ある距離（京都1400/1600/2000、阪神1400）は、主な重賞で使うほうを選んだ
- **コーナーの半径・坂の位置と形**：Claude の推定。公式の高低断面図とは照合していない。ユーザーから正確な資料が届いたら差し替える
- **ゴール板から1コーナーまでの長さ**：公表値が見つからないので仮に20m以上とした

## ゲームでの近似

- コースは「直線2本＋半円カーブ2本」の楕円。推定したコーナー半径で2つのカーブを作り、1周の残りを2本の直線に等分する
- 直線距離が楕円の直線より長い東京などは、はみ出した分を4コーナーの出口側として扱う（実際の東京の4コーナーはゆるやかで、直線に向くまでが長い）
- 発走地点はゴールから距離ぶん戻った位置。実際の発走地点（引き込み線など）は再現していない
- ダートの距離はゲームの標準距離（1200/1600/2000m）のままで、その場に実在する距離かどうかは見ていない（例：中山ダート1600mは実在しないと思われるが確認していない）

## コースの違いがレースに与える効果

- **直線の長さ**：追い出しの伸びに脚質ごとの補正を入れている（直線が長いほど差し・追込、短いほど逃げ・先行）。直線が長い場では、後ろの馬が直線で外から押し上げてから追い出す
- **コーナーの半径**：小回りほど3〜4コーナーで外から押し上げにくく、外を回る距離ロスも大きい
- **坂**：上りでは速度が落ちてスタミナを多く使い、下りでは少し速く楽になる

1000レースほど回した結果（芝1600・2000m、14頭立て）の脚質の勝率（頭数の割合から見た期待値との比）は、東京が差し・追込で高く、中山が逃げ・先行で高い。実際の傾向と向きは合わせたが、強さは実データで確かめていない。
