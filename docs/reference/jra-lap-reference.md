# 日本競馬（JRA）ラップタイム参考値

> ユーザー提供の参考値（2026-10-09）。`src/sim/reference.ts` に同じ値を機械可読で置いている。

## このファイルの位置づけ
- JRA中央場・古馬・中〜上級クラスを想定した**おおよその目安値**。実データの集計値ではない。
- 用途：データ検証時の妥当性チェック（外れ値検出）、デフォルト値、仮置きの初期値。
- 実データ（netkeiba / JRA-VAN 等）が手元にある場合は**必ず実データを優先**し、この値で上書きしないこと。
- この値を根拠に断定的な結論を出さないこと。不明な条件（地方競馬、障害、2歳戦など）は推測で埋めず「参考値なし」と扱うこと。

## 用語
- ラップ：1ハロン（200m）ごとの通過タイム（秒）
- 平均ラップ：走破タイム ÷ (距離 / 200)
- 上がり3F：ラスト600mのタイム（勝ち馬・上位馬の目安）
- 道悪：重・不良。稍重はおおむね良と道悪の中間

## 芝・道悪（重〜不良）
- 走破タイム：良より +1〜3秒以上**遅い**
- 平均ラップ：+0.2〜0.4秒
- 上がり3F：35.5〜37.5（不良では38秒台もある）

## ダート・道悪（重〜不良）
- 砂が締まるため、良より**速くなる**（芝と逆）
- 走破タイム：-0.5〜1.5秒
- 上がり3F：-0.5〜1.0秒

## ラップ形状の傾向
- 1F目はゲート発走のためほぼ12秒台（最速ラップにはならない）
- 短距離：2F目が最速ラップになりやすい
- 中長距離（芝）：中盤が最も緩み、ラスト2F目が最速になりやすい
- ダート：前半速く後半失速する形が多く、最遅ラップはゴール前1Fになりがち

## 補正要因（値は不確か。使う場合は実データで検証すること）
- クラス差：未勝利とG1で走破タイム1〜2秒差
- 競馬場：東京芝は速い、中山・阪神内回りは上がりがかかる
- 季節・開催時期（開幕週は速く、開催後半は時計がかかる）
- 地方競馬は対象外
