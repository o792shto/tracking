# 2026年 JRA主要4場 平地重賞一覧（ユーザー提供）

- 出典：デイリースポーツ「2026年JRA重賞成績」（2026/10/9時点で取得）
- 障害重賞は除外。対象は東京・中山・京都・阪神の4場のみ
- 10/10以降は予定。変更の可能性あり
- 年齢・牝馬限定はユーザーが追記（エプソムCの年齢は要確認）
- 合計98レース。表を数えると G1 22 / G2 36 / G3 40（提供時の見出しの G1 21 / G2 35 / G3 42 とは異なる）。場別は 中山25・東京28・京都24・阪神21

## ゲームでの扱い

- 1年 = 98開催日。各日のメインレース（11R）にこの重賞を1つずつ割り当てる。1日12R
- 2歳戦はG1以外をすべて「オープン」に置き換える
